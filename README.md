# quantum-logic-gates-qiskit
Qiskit-based implementation and simulation of classical logic gates and arithmetic circuits on quantum circuits.
# Classical Logic Gates with Qiskit | Qiskit ile Klasik Mantık Kapıları

## TR

Bu proje, klasik mantık kapılarını ve toplama/çıkarma devrelerini Qiskit ile simüle eder. Devrelerin çıktıları klasik doğruluk tablolarıyla karşılaştırılır. Proje geliştirme aşamasındadır.

- `logic_gates_and_arithmetic_circuits.ipynb`: Mantık kapıları, multiplexer, toplayıcılar ve çıkarıcılar.
- `ripple_carry_adder_subtractor.ipynb`: 10 bitlik toplama ve çıkarma örneği.
- `logic_gates_fake_backend.ipynb`: AND ve OR kapılarının FakeManilaV2 ile simülasyonu.

## ENG

This project simulates classical logic gates and addition/subtraction circuits with Qiskit. Circuit outputs are compared with classical truth tables. The project is still in development.

- `logic_gates_and_arithmetic_circuits.ipynb`: Logic gates, a multiplexer, adders, and subtractors.
- `ripple_carry_adder_subtractor.ipynb`: A 10-bit addition and subtraction example.
- `logic_gates_fake_backend.ipynb`: AND and OR simulations using FakeManilaV2.
